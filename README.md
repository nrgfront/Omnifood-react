# 🍽️ Omnifood Planner (React + Vite)

A modern meal planning application built with React and Vite. Users can explore meals, filter them by dietary preferences, search recipes, and create personalized meal plans while tracking total calories.

## ✨ Features

- 🔍 Search meals by name
- 🥗 Filter recipes by dietary preferences
  - Vegan
  - Vegetarian
  - Gluten-Free
  - Dairy-Free
  - Paleo
  - High-Protein

- ➕ Add and remove meals from the planner
- 🔥 Automatically calculate total calories
- 🌙 Toggle between Light and Dark mode
- 📱 Fully responsive design
- 💾 Persist selected meals using localStorage
- ⚡ Fast performance powered by Vite

## 🛠️ Tech Stack

- React
- Vite
- React Router
- Context API
- CSS Modules
- React Icons
- LocalStorage
